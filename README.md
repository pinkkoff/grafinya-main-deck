## Что внутри

1. Знакомство и вопросы о текущих задачах.
2. **Зачем менять Grafana:** проблемы обновлений, безопасности и поддержки, требования регуляторов к ПО из реестра.
3. **Что такое Графиня:** главная, витрины, источники данных, оповещения, витрины для разных ролей.
4. **Пульт + Графиня:** замена пары Zabbix + Grafana, ресурсно-сервисная модель.
5. **Почему Графиня:** переезд с Grafana, сравнение, enterprise-функции, 117 приказ ФСТЭК, безопасная разработка, сопровождение.
6. Следующие шаги.

На слайдах 6, 7, 8, 9 и 12 – живые экраны интерфейса Графини: витрина обновляется и переключает ЦОД, работает поиск по плагинам, по правилам оповещений можно кликать, в ресурсно-сервисной модели проблемы поднимаются до услуги. Данные на экранах демонстрационные.

## Как устроено

Один HTML-файл без сборщиков и внешних зависимостей. Шрифты Montserrat и JetBrains Mono лежат локально в `assets/fonts/`, картинки и логотипы – в `assets/`. Страница собирается из рабочей версии презентации, заметки докладчика при сборке вырезаются. Поисковым системам страница закрыта (`noindex`).
